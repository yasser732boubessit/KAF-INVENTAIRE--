# خطة تنفيذ: تحويل KAF-INVENTAIRE إلى PWA متكامل ودليل التشغيل المحلي

بناءً على اختيارك لتفعيل **تثبيت التطبيق كـ PWA** و**تشغيل الكود محلياً عبر Node.js**، هذه خطة العمل التفصيلية لتجهيز المشروع بالكامل.

---

## 1. الأهداف الرئيسية

1. **تحويل التطبيق إلى Progressive Web App (PWA) معتمد واحترافي:**
   - تثبيت التطبيق بنقرة زر واحدة على الهاتف (Android / iOS) والكمبيوتر (Windows / Mac / Linux).
   - العمل بدون إنترنت كلياً (Offline Caching) لجميع ملفات التطبيق (HTML, JS, CSS, الأيقونات، الخطوط).
   - توفير زر تثبيت مخصص في شريط النظام العلوي (Install PWA Prompt) يظهر للمستخدم في المتصفح.
   - تجهيز ملف البيان `manifest.webmanifest` وأيقونات بأحجام قياسية (192x192, 512x512, maskable) وألوان المتجر المتناسقة مع هوية التطبيق (`#0F172A` و `#16A34A`).
   - إعداد Service Worker عبر `vite-plugin-pwa` للتخزين المؤقت المسبق (Pre-caching).

2. **تجهيز دليل تشغيل الكود محلياً (README.md متكامل واحترافي):**
   - خطوات استنساخ المشروع وتثبيت الحزم (`npm install`).
   - تشغيل بيئة التطوير (`npm run dev`) على المنفذ 3000.
   - بناء النسخة الإنتاجية (`npm run build`) ومعاينتها (`npm run preview`).
   - متطلبات التشغيل وإعدادات بيئة العمل.

---

## 2. خطوات التنفيذ التقنية

### المرحلة الأولى: إعداد أدوات PWA وتوليد الأصول
* تثبيت الحزمة الرسمية `vite-plugin-pwa` كـ devDependency.
* توليد وإنشاء أيقونات PWA ذات الجودة العالية بالألوان المعتمدة (أخضر صناعي `#16A34A` وخلفية داكنة `#0F172A` بشعار ماسح الباركود وجرد الأصول):
  - `pwa-192x192.png`
  - `pwa-512x512.png`
  - `apple-touch-icon.png`
  - `favicon.svg`
* تكوين `vite.config.ts` لإضافة مكون `VitePWA` مع استراتيجية `generateSW`، و`registerType: 'autoUpdate'`.

### المرحلة الثانية: ربط واجهة المستخدم ودعم التثبيت المباشر
* إضافة زر تفاعلي «تثبيت التطبيق | Install App» في الشريط العلوي المدمج (يظهر عند توفر حدث `beforeinstallprompt`).
* إضافة إشعار عند توفر تحديث جديد دون انقطاع العمل الميداني.
* دعم شريط الإشعارات عند فقدان أو استعادة الاتصال بالإنترنت مع مؤشر Offline جاهز.

### المرحلة الثالثة: إعداد ملف التوثيق والتشغيل المحلي `README.md`
* إنشاء توثيق مفصل باللغتين العربية والإنجليزية يشرح:
  - بنية المشروع والأدوات المستخدمة (React 19, TypeScript, Tailwind CSS, Vite, Lucide Icons).
  - أوامر التشغيل والبناء والاختبار.
  - كيفية تثبيته على أجهزة المخازن وهواتف فرق الجرد الميداني.

---

## 3. التحقق والاختبار (Verification)

* فحص توافق PWA عبر فحص الـ Manifest والـ Service Worker في البناء الإنتاجي.
* تجربة أمر `npm run build` للتأكد من خلو المشروع من أية أخطاء تجميع.
* التأكد من استمرار عمل التخزين المحلي IndexedDB بدون أي مشاكل أثناء العمل بلا إنترنت.
